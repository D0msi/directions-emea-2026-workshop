# Does this test assert anything meaningful?

**Side A:** A test that inserts a record and then asserts it can Get it only tests the platform. Rewrite it or delete it.

**Side B:** Smoke tests are cheap and catch broken table triggers, permissions or schema problems early. Not every test has to prove business logic.
